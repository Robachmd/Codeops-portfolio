# 🍽️ Habesha Eatery

A responsive Ethiopian restaurant website built with **HTML5 and CSS3**, showcasing traditional Ethiopian dishes through a clean, modern, and user-friendly interface.

🔗 **GitHub Repository:**
https://github.com/Robachmd

---

## 📖 About the Project

**Habesha Eatery** is a frontend restaurant website created to demonstrate responsive web design, semantic HTML, modern CSS layouts, animations, and multi-page navigation.

The website provides a digital restaurant experience where users can explore Ethiopian dishes, view prices and ingredients, learn about the restaurant, make a reservation, and access the login page.

The project was developed as a practical frontend development project with a focus on **responsive design, accessibility, layout systems, and clean user interfaces**.

## 📱 Responsive Design

Habesha Eatery is designed to work across different screen sizes, from approximately **360px mobile screens to wide desktop displays**.

The menu layout adapts using CSS Grid and media queries:

| Device     | Layout    |
| ---------- | --------- |
| 📱 Mobile  | 1 column  |
| 📱 Tablet  | 2 columns |
| 💻 Desktop | 3 columns |

Additional responsive techniques include:

* Flexible widths
* `clamp()` typography
* CSS Grid
* Flexbox
* Media queries
* Horizontal scrolling for selected menu sections
* Responsive images and containers

## 🚀 Getting Started

### Requirements

Before running the project, make sure you have:

* A modern web browser such as Chrome, Firefox, or Edge
* [Visual Studio Code](https://code.visualstudio.com/) (recommended)
* Live Server extension for VS Code (recommended)
* Git (optional, for cloning the repository)

### 1. Clone the repository

```bash
git clone https://github.com/Robachmd/Habesha-Eatery.git
```

### 2. Navigate to the project

```bash
cd Habesha-Eatery
```

### 3. Open the project

Open the project folder in Visual Studio Code.

### 4. Run the website

Open `final_project/index.html` using **Live Server** or directly open it in your browser.
