# Currency Converter

A simple currency converter web application built with HTML, CSS, and JavaScript.

## Features

- Convert between different currencies
- Fetch real-time exchange rates from a public API
- Support multiple currencies
- Display conversion results
- Add currencies to a watchlist
- Remove currencies from the watchlist
- Save data using localStorage
- Restore saved data after refreshing
- Display loading, success, and error messages
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- DOM Manipulation
- LocalStorage

## API

This project uses the ExchangeRate API:

https://open.er-api.com/v6/latest/ETB

The exchange rates are based on Ethiopian Birr (ETB).

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

No installation or backend is required.
